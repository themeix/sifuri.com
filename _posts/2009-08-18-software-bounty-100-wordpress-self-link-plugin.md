<p>Reading a recent comment on the WordPress users&#8217; group on <a href="http://www.triiibes.com/main/authorization/signIn?target=http%3A%2F%2Fwww.triiibes.com%2F">Triiibes</a>, I realized that a new user was having a problem that actually does affect me as well. The user complained that he couldn&#8217;t figure out how to post a link to a previous post.</p>
<p>Of course, the response is you type the anchor text, switch to a different window/tab, copy the url to clipboard, switch back to post page, click the link icon, paste URL, and hit insert. Bingo! Easy as pie, once you know what it is and that it&#8217;s no different from any other link.</p>
<p>But that&#8217;s not the heart of the question; it&#8217;s that when <a href="http://www.problogger.net/">blogging gurus</a> talk about adding value to your posts by making reasonable intra-blog <a href="http://www.problogger.net/archives/2009/04/13/interlink-your-old-blog-posts/">interlinks</a>, WordPress effectively treats all my existing posts as external.</p>
<p>This bounty, then, is for a small plugin, compatible with WP 2.8+, that would implement some mechanism to make linking to internal posts on the same blog much easier.</p>
<p>There are a number of ways that you might address this problem, so there will be no constraints; this means, however, that judging a winner will be more subjective. I will judge finalists and ask a programmer/designer from the aforementioned triiibes group to select a winner.</p>
<p>This is also a work-for-hire but we&#8217;ll agree to a suitable CC license so you have an opportunity to redistribute and even sell.</p>
<p>(Incidentally, the reasons that I want all these bounties to be works for hire are that (a) I&#8217;m paying for your work, even if it&#8217;s not a full contract rate, and (b) this way, I can be sure to control the rights and allow for greater distribution. Giving a prize and then letting someone keep the results proprietary seems to defeat the purpose. I&#8217;ve provided the ideas, so if that&#8217;s what you want to do as a programmer, just build it, give appropriate credit, and don&#8217;t submit it for an award.)</p>
