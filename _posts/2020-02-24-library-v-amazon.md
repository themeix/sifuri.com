<p>At some point I looked over my Amazon wish list and saw a lot of books that I wanted to read but wasn’t sure I really wanted to keep for a long time. So I wondered if there was a tool that would track my wishlist and then pop up and tell me if the book was available in my local library.</p>
<p>I saw a mention in Lifehacker (and then again recently in Cool Tools) for a Chrome plugin that does this for some library networks. <a href="https://www.libraryextension.com/">Library Extension</a> does exactly that. I get excited when I see these things making their way into the world, even if I’m not the one doing it, or getting credit for it, or anything at all. I am happy when people have slightly easier lives.</p>
<p>A different angle on this is creating a tool/script/webapp/Alfred workflow for sending a book name to my library&#8217;s auto-bookbag interface and adding it to my list. What we should do with our libraries is treat them like our Netflix queues, where we add books and eventually they make it to the top of the list (and sometimes a book jumps the queue, like when <a href="https://www.youtube.com/playlist?list=PLD7E21BF91F3F9683">Sapolsky</a> recommends <a href="https://smile.amazon.com/Chaos-Making-Science-James-Gleick/dp/0143113453/ref=sr_1_1?crid=D0I2JMIHPBT7&amp;keywords=chaos+james+gleick&amp;qid=1582500428&amp;sprefix=chaos+jam%2Caps%2C140&amp;sr=8-1">James Gleick&#8217;s Chaos</a>).</p>
<p>I think that there might also be a related need for an <a href="https://en.wikipedia.org/wiki/International_Standard_Book_Number">ISBN</a> cross-lookup tool to get the same book in different formats (or whatever might trigger different ISBNs for what people would consider the same book).</p>
